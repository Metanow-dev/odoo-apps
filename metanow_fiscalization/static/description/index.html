Fiskalizimi me efis / Fiscalisation with efis

Faturat e klientëve fiskalizohen nga efis. / Customer invoices fiscalised by efis.

The module sends each posted customer invoice to efis and stores on the invoice what efis returns: the fiscal number, the issuer security code, the registration code and the verification URL. It does not sign, number or compute a security code, it holds no certificate or key, and it never talks to the tax authority. The certificate stays in efis.

Moduli dërgon te efis çdo faturë klienti të postuar dhe ruan në faturë atë që kthen efis: numrin fiskal, kodin e sigurisë së lëshuesit, kodin e regjistrimit dhe adresën e verifikimit.

What it does

  • Checks the invoice as efis would before a number is spent. If efis would not accept it, the posting is rolled back with the list of problems and nothing is sent.
  • Queues accepted invoices and sends them right after posting. Two scheduled actions send the queue and read the states.
  • Adds a "Fiskalizimi / Fiscalisation" tab to the invoice with the fiscal state, the fiscal number, the security code, the registration code and the verification URL.
  • Prints the fiscal number, the NIVF, the NSLF and the QR code of the verification URL on the invoice PDF.
  • Never lets an invoice sent for fiscalisation go back to draft, be cancelled or be deleted. It is corrected only by a corrective document.

Requirements

  • An efis account. The module pairs with efis using a single-use code from the efis web app.
  • Odoo 20 with Invoicing, on Odoo.sh or self-hosted. Odoo Online cannot load Python modules.
